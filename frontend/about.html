About Our Project

Smart Blood Donation and Emergency Matching System

Project Overview

Blood is very important in emergency situations. Sometimes finding suitable blood donors is difficult. Our project, Smart Blood Donation and Emergency Matching System, helps connect blood donors with patients who need blood.

Donors can register their details through our website. Patients can submit their blood requirements. Users can search for potential donors based on blood group and city.

Project Objectives

  • To make blood donor registration easy.
  • To allow patients to submit blood requests.
  • To search potential donors by blood group and city.
  • To store donor and patient request details.
  • To support faster communication during emergencies.

Technologies Used

  • HTML - Website Structure
  • CSS - Website Design
  • JavaScript - Frontend Functionality
  • Node.js - Backend
  • Express.js - Server
  • MySQL - Database
